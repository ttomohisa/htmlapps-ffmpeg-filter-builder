使い方と注意事項

      
    

    

      
      
基本操作

      
    
        
  1. Inputノードを選び、MP4動画を読み込みます。読み込んだファイルは外部へ送信されません。
    2. 
        
  2. 「かんたんレシピ」からやりたい処理を選び、「Graphへ展開」を押します。
    3. 
        
  3. 必要なら展開されたノードを編集し、「プレビューを更新」で結果を確認します。
    4. 
        
  4. 問題なければ「動画を書き出す」で動画全体へ同じGraphを適用し、完了後に保存します。
    5. 
      

      
スマートフォンでは下部のRecipeからレシピを選べます。ノードをタップするかEnter / Spaceで設定を開き、「完了」で閉じます。選択ノードの入力接続は「その他」→「入力を切断」で外せます（元に戻す対応）。

      
Graphの制約

      
    
        
  • v0.8.0はVideo / Audio / Textの型付きGraphをRecipeから生成し、同じGraphをPreviewとFull Renderに使います。
    • 
        
  • Cycle、未接続branch、1つのportへの複数接続は拒否します。
    • 
        
  • SplitのA/BとOverlayのMAIN/OVERを使ってbranchを明示的に接続します。
    • 
      

      
キーボード操作

      
    
        
  • Delete / Backspaceで選択したノードまたは接続を削除します。
    • 
        
  • Ctrl / Cmd + Zで元に戻し、Ctrl / Cmd + Shift + Z または Ctrl / Cmd + Yでやり直します。
    • 
        
  • 矢印キーで選択ノードを1px移動し、Shift + 矢印キーで10px移動します。
    • 
        
  • Graph上でCtrl / Cmd + Aですべてのノードを選択し、Escで選択や接続操作を解除します。
    • 
        
  • Graph上でFを押すと全体表示、Spaceを押しながらドラッグするとCanvasを移動できます。
    • 
      

      
標準版と高速版

      
    
        
  • index.html はsingle-thread版です。保存したHTMLを file:// から直接開く用途を正式サポートします。
    • 
        
  • index.mt.html はmulti-thread版です。SharedArrayBufferを使うため、COOP / COEPを付けたHTTP(S)配信が必要です。
    • 
      

      
プライバシー

      
素材ファイル・Graph・テキスト・設定・生成結果はブラウザー内だけで処理します。FFmpeg runtimeと標準フォントもHTMLへ埋め込まれ、実行時にGitHub・Google Fonts・CDNへアクセスしません。

      
v0.8.0の範囲

      
    
        
  • Recipeは実際のノードへ展開します。Graph JSONには素材のファイル名・サイズなどの情報だけを保存し、ファイル本体やローカルパスは保存しません。再読込後は「素材をまとめて再選択」から元ファイルを選ぶと一致するInputへ自動で戻せます。
    • 
        
  • Full RenderはPreviewと同じGraphを動画全体へ適用し、H.264 / AAC MP4としてブラウザー内で生成します。生成結果は明示的に保存できます。
    • 
        
  • 大きな動画はブラウザーのメモリ制限や端末性能により処理できない場合があります。
    • 
      

      
標準版はネットワークを切った状態でも、Graph編集・コンパイル・Preview・Full Render・保存まで利用できます。
